SQL and Database:

Structured Query Language

Primary Key: The unique identifier for each entry (2 constraints: has to be unqiue and not null)

Foreign Key: 

Candidate Key: Anything that COULD be a unique identifier for an entry

Composite Key: A combination of two or more candidate keys. (Example: Search for both House number and Street Address for a value)

Atomic Data: Standalone data (smallest individual piece/separation)

First normal form - every table has a primary key (and is atomic)
1NF - The Key

Second normal form - 
2NF - The Whole Key

Third normal form -
3NF - Nothing But The Key

DQL - Data Query Language
DML - Data Manipulation Language
DDL - Data Definition Language
DCL - Data Control Language

Single line comment can be done using --
Multi line comment can be done using /* */

DQL - Data Query Language
Key words:
	- SELECT: Retrieve data, select the columns from the resulting set
	- FROM: The table(s) to retrieve data from
	- WHERE: A condition filter of the dta
	- GROUP BY: Group data based on one or more columns
	- HAVING: A conditional filter of the grouped data
	- ORDER BY: Sort the data
