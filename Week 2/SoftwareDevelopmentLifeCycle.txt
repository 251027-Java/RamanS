Software Development Life Cycle (SDLC) - Iterative

Planning -> Requirements -> Design 0> Implementation -> Testing -> Deployment -> Loopback around

Structure of a USER Story:
- "As A" who
- "I want to" what
- "So that" why

public class App {
	public static void main(String[] args) {
		System.out.println("Hello World!");
	}
}
